## About

Staff Software Engineer at **Visa Inc.** with 10+ years building global payments, risk
and fraud platforms. I lead platform, observability and agentic AI initiatives on
**Visa Risk Manager** — the fraud-decisioning platform 1,000+ issuing banks use to
approve or decline transactions in real time.

Before Visa: **Infosys Ltd.** (Senior Systems Engineer, 2011–2014) delivering Java and
web features for EA Sports' Origin platform and Android set-top-box capability for
Comcast's Skype on XFINITY, and a software engineering internship at
**Walmart Global Tech (@WalmartLabs)** building one of Walmart's first driver-facing
delivery apps.

**M.S. Software Engineering**, San Jose State University · **B.E. Computer Science**,
Visvesvaraya Technological University.
